# 미터 도면의 치수 스타일과 글자 크기

치수를 하나라도 넣기 전에 한 번:

```json
cadcraft_execute {"command": "dimstyle",
  "params": {"name": "M", "current": true,
             "DIMTXT": 0.2, "DIMASZ": 0.15, "DIMEXO": 0.1, "DIMEXE": 0.1,
             "DIMGAP": 0.05, "DIMSCALE": 1, "DIMDEC": 2}}
```

| 변수 | 값 | 뜻 |
|---|---|---|
| `DIMTXT` | 0.2 | 치수 글자 높이(m) |
| `DIMASZ` | 0.15 | 화살표 크기 |
| `DIMEXO` | 0.1 | 치수 보조선이 대상에서 떨어지는 거리 |
| `DIMEXE` | 0.1 | 보조선이 치수선 너머로 나가는 길이 |
| `DIMGAP` | 0.05 | 치수선과 글자 사이 |
| `DIMSCALE` | 1 | 전체 배율(미터 그대로) |
| `DIMDEC` | 2 | 소수 자리(0.01 m) |

글자 높이(미터 도면 기준):

| 요소 | 높이 |
|---|---|
| 방·구역 이름 | 0.3 |
| 문·창 표시, 가구 이름 | 0.2 |
| 도면 제목 | 0.5 |
| 치수선 위치 | 벽에서 0.8 m 바깥 |

도면이 아주 크거나(수십 m 넘는 배치도) 작으면 위 값 전체에 같은 배율을 곱한다(`DIMSCALE` 을 바꾸거나 값을 직접).
그린 뒤 `cadcraft_render` 로 글자가 읽히는 크기인지 본다.
