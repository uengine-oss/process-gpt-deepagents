# 한글(HWPX) 문서 만들기

## 0. 먼저 볼 사실

- **양식 주소(template_url)** 는 사람이 쓰지 않는다. 시스템이 메시지 끝에 사실로 붙여 준다(예: 「한글 양식 주소: …」,
  「hwpx template: …」). 사용자가 첨부한 .hwpx 가 있으면 그것이 이번 양식이다.
- **산출물 위치**는 메시지의 파일 위치 규칙(이 대화 전용 산출물 폴더)을 따른다.
- 편집기에 한글 문서가 열려 있고 그 문서를 고쳐 달라는 요청이면 이 스킬이 아니라 `ieumoffice-live-edit` 이다.

## 1. generate_hwpx 가 도구 목록에 있고 양식 주소가 있으면

`generate_hwpx` 를 한 번 부른다.
- `template_url`: 0절의 양식 주소 그대로.
- `report_topic`: 문서 제목.
- `report_description`: 문서에 들어갈 내용 **전부** — 항목·표의 값·숫자·날짜·담당자. 사용자가 준 것을 빠짐없이,
  지어낸 숫자 없이. 영어로 써 달라는 요청이면 「영어로 작성」을 여기에 적는다.
- `reference_text`: 사용자가 붙여 넣거나 첨부한 자료의 본문(있을 때).
- 결과로 받은 파일·주소를 답에 적는다. 도구가 있었는지 없었는지는 답에 쓰지 않는다.

## 2. 도구가 없거나 양식 주소가 없으면 — 샌드박스에서 직접

HWPX 는 OWPML XML 을 묶은 zip 이다. 순서와 주의할 점은 `references/template-fill.md` 에 있다 — 만들기 전에 읽는다.

1. 양식이 있으면 내려받는다. 주소의 호스트가 `127.0.0.1`·`localhost` 면 샌드박스 안에서는
   `host.docker.internal` 로 바꿔 받는다(샌드박스의 localhost 는 샌드박스 자신이다).
2. 양식의 `Contents/section0.xml` 에서 채울 자리(제목·자리 표시 글·표 칸)를 찾아 글을 바꾸고,
   필요한 문단·표 행을 이웃 것을 본떠 늘린다. 서식(문단·글자 모양 id)은 그대로 둔다.
3. 양식이 없으면 references 의 최소 구조로 새 문서를 만든다.
4. zip 을 다시 묶는다 — `mimetype` 을 **압축 없이 첫 항목**으로, 나머지 항목 순서는 원본 그대로.
5. 산출물 폴더에 `.hwpx` 로 저장하고, 다시 열어(zip 목록, XML 파싱, 바꾼 글 검색) 깨지지 않았는지 확인한 뒤 경로를 답에 적는다.

`.hwp`(옛 이진 형식)로 달라고 해도 만들 수 있는 것은 `.hwpx` 다 — 한글에서 열리고 다른 이름으로 .hwp 저장이 된다고 알린다.

## 3. 쓰지 않는 경우

- Word·PDF·PowerPoint·Excel 파일 → 그 형식의 스킬(docx·pdf·pptx·xlsx).
- 「한글로 번역」「한글 맞춤법」처럼 한국어를 뜻하는 경우 → 글로 답한다.
- 열린 한글 문서를 화면에서 고치기 → `ieumoffice-live-edit`.
