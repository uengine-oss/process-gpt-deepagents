# Slack — Lite 커넥터 `pgpt-slack`

| 도구 | 인자 | 하는 일 |
|---|---|---|
| `slack_list_channels` | `limit`(≤200) | 사용자가 볼 수 있는 채널 목록(id·이름) |
| `slack_read_channel` | `channel`(id 또는 `#이름`), `oldest`(유닉스 초, 이후 메시지만), `limit`(≤200) | 최근 메시지 |
| `slack_post_message` | `channel`, `text` | 사용자 이름으로 게시 |

## 요령

- 채널 이름이 정확하지 않으면 `slack_list_channels` 로 후보를 찾는다. 비슷한 채널이 여럿이면 묻는다.
- 「지난주」「오늘」 같은 기간은 `oldest` 로 자른다(현재 시각 기준으로 유닉스 초 계산).
- 요약할 때 누가 무엇을 말했는지와 결정·할 일을 가른다. 메시지를 지어내지 않는다.
- 공유 채널에 올리기 전에는 올릴 글을 보여 주고 확인을 받는다(도구 설명에도 적혀 있다).
- 비공개 채널·DM 은 사용자가 그 채널에 들어 있어야 읽힌다.
